## 💡 使用建议

1. **从第 1 天开始**，不要跳着看
2. 每天完成后在对应文件里打勾（GitHub 上勾选 checkbox）
3. 遇到不懂的，先看"卡住了怎么办"，再问 AI
4. **完成比完美更重要**——今天学了 10 分钟，比明天"打算学 2 小时"好得多

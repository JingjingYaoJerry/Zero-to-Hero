# 第 27 天：修正薄弱点

> 💡 **今天只需要 20 分钟就能完成最小版本**  
> 今天的重点：修复你在模拟面试中暴露的薄弱点

---

## 📋 今日概览

昨天的模拟面试一定让你发现了一些薄弱点。  
今天专门针对这些薄弱点做深化和修复。

**不要跳过这一天。越弱的地方，越值得补。**

---

## ⏱️ 最小启动版本（20 分钟）

**打开昨天的模拟面试反馈，选出最薄弱的 1 个知识点，做一次针对性深化：**

```
在昨天的模拟面试中，我对 [薄弱知识点] 的理解不够清楚。
请帮我：
1. 重新从头解释这个概念（假设我完全不懂）
2. 用一个直觉例子说明
3. 给我出 3 道专项题，从易到难
4. 给我一个 1 分钟口述版本的模板，让我下次遇到这道题时能清楚作答
```

---

## 🚀 完整版任务（45 分钟）

### 步骤 1：整理所有薄弱点（10 分钟）

从以下来源汇总你的薄弱点：
- 昨天（Day 26）模拟面试的反馈
- 三周复盘表中标注的薄弱点
- 错题本中的记录

列出优先级：

```
## 我的薄弱点清单（按重要程度排序）

1. [最重要/最可能考的]：___
2. [次重要]：___
3. [第三重要]：___
```

### 步骤 2：针对性深化（25 分钟）

对排名前 2 的薄弱点，各用 12 分钟做深化：

**使用的提示词：**
```
针对 [薄弱知识点]，帮我做针对性补强：
1. 这个概念的核心是什么（最简洁版本）
2. 我最可能理解错的地方是哪里
3. 用 3 个问题检验我是否真的理解了
4. 给我一个面试中的"万能解释框架"（即使忘了细节，这个框架也能撑起答案）
```

### 步骤 3：重新测试（10 分钟）

对修正的薄弱点，再做一次自测：
- 合上笔记
- 口述（或文字）解释这个概念
- 和答案对比，看是否有提升

---

## ✅ 完成标准

- [ ] 列出了至少 3 个薄弱点
- [ ] 对最重要的 2 个薄弱点做了针对性深化
- [ ] 修正后能更清楚地解释这些概念

---

## 🤖 今日 AI 提示词

### 万能薄弱点修复提示词
```
我在面试中被问到 [问题]，我的回答不够好：
[你的不完整回答]

请帮我：
1. 指出我的回答缺少哪些关键要素
2. 给我完整答案框架（要点式）
3. 给我一个 90 秒口述版本
4. 给我 2 道变体题，帮我举一反三
```

### 理解困难修复
```
我一直搞不清楚 [概念 A] 和 [概念 B] 的区别。
请用 3 种不同方式解释这个区别：
1. 定义层面（技术定义）
2. 直觉层面（打个比方）
3. 使用层面（什么时候用 A，什么时候用 B）
最后给我一句话总结，让我能记住它们的区别。
```

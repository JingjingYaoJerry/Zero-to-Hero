## 🧭 根据你的方向选择今天的主题

### 🔤 NLP / 大模型方向 → 学 RAG

**提示词：**
```
请讲解 RAG（Retrieval-Augmented Generation，检索增强生成）：
1. RAG 解决什么问题（LLM 的知识更新问题）
2. RAG 的基本架构（检索 + 生成）
3. 向量数据库在 RAG 中的作用
4. RAG vs 微调（Fine-tuning）的选择依据
5. RAG 的工程实现要点（分块、嵌入、检索、生成）
6. 面试 1 分钟回答
```

**核心要点：**
- LLM 训练数据有截止日期，知识可能过期
- RAG：每次生成前，先检索相关文档，给 LLM 提供实时上下文
- 向量数据库：把文档变成向量，通过相似度搜索找相关文档

### 👁️ CV 方向 → 学 EfficientNet 或 Foundation Models

**EfficientNet 提示词：**
```
请讲解 EfficientNet：
1. 模型缩放（Model Scaling）的三个维度是什么（深度/宽度/分辨率）
2. NAS（神经架构搜索）如何找到基础架构
3. Compound Scaling 是什么
4. EfficientNet 在参数量和精度上的 trade-off
5. 面试 1 分钟回答
```

### 📊 推荐 / 广告方向 → 学双塔模型（DSSM）

**提示词：**
```
请讲解双塔模型（DSSM / Two-Tower Model）在推荐系统中的应用：
1. 为什么召回阶段需要双塔模型
2. User Tower 和 Item Tower 分别学什么
3. 对比学习（Contrastive Learning）在双塔中的应用
4. 如何处理负采样（Hard Negative Sampling）
5. 双塔模型的离线 vs 在线服务方式
6. 面试 1 分钟回答
```

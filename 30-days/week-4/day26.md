# 第 26 天：AI 模拟面试（第一轮）

> 💡 **今天只需要 20 分钟就能完成最小版本**  
> 今天是你第一次完整的模拟面试

---

## 📋 今日概览

今天模拟一次真实面试。规则：
1. **不能看笔记**（这是关键）
2. 用语言（口头或文字）回答，不是填空
3. 完成后让 AI 给你打分和反馈

---

## ⏱️ 最小启动版本（20 分钟）

**做一次 20 分钟的迷你模拟面试：**

```
请扮演资深机器学习工程师面试官，对我进行一次技术面试。
规则：
- 按顺序出 5 道题
- 等我完整回答后，给我评分（1-5）并指出关键遗漏
- 5 题全部完成后，给我一个综合反馈和改进建议

题目范围：
1. 基础原理题（如 Transformer、Adam 等）
2. 方向专题题（[你的方向]）
3. 工程实践题
4. 系统设计题（简单版）
5. 行为/经历题（请结合你读过的论文谈一个有深度的技术理解）

开始第一题。
```

---

## 🚀 完整版模拟面试（60 分钟）

### 第一轮：基础技术（20 分钟）

```
请模拟面试，出 8 道技术题：
- 3 道基础原理（Adam/Transformer/BatchNorm 相关）
- 3 道方向专题
- 2 道工程类

每题等我回答后反馈，再出下一题。
```

### 第二轮：系统设计（20 分钟）

```
面试题：请设计一个 [推荐系统 / 文本分类系统 / 图像识别系统]。
你有 15 分钟，请系统性地讲解你的设计思路。
等我回答后，给我专业反馈。
```

### 第三轮：综合反馈（20 分钟）

```
感谢你的模拟面试。现在请给我：
1. 今天表现的综合评分（1-10）
2. 最强的 3 个方面
3. 最需要改进的 3 个方面
4. 明天重点复习什么的建议
5. 如果你是面试官，你会给我发 offer 吗，为什么
```

---

## ✅ 完成标准

- [ ] 完成了至少 5 道题的不看笔记回答
- [ ] 拿到了 AI 的综合反馈
- [ ] 记录了本次模拟面试的薄弱点（加入错题本）

---

## 🤖 面试技巧补充

```
请给我机器学习面试的实战技巧：
1. 被问到不会的题时，怎么处理最好
2. 如何把"不太熟悉"的话题引导到自己熟悉的方向
3. 技术题回答时，什么样的结构最让面试官满意
4. 有什么常见的面试"表达陷阱"要避免
```

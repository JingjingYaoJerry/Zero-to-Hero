# 第 22 天：整理面试回答模板库

> 💡 **今天只需要 20 分钟就能完成最小版本**  
> 第四周目标：把知识变成面试竞争力

---

## 📋 今日概览

第四周是工程化与面试化阶段。  
今天你要建立一个**可以直接在面试中使用的回答库**。

---

## ⏱️ 最小启动版本（20 分钟）

**用 AI 生成你的 5 个核心面试答案模板：**

```
我是一名 ML 工程师候选人，正在准备面试。
请帮我整理以下 5 个问题的面试回答模板（每个 1-2 分钟口述版本）：
1. "请简单介绍一下 Transformer 的工作原理"
2. "你了解哪些防止过拟合的方法，各有什么优缺点"
3. "BERT 和 GPT 有什么区别，各适合什么场景"
4. "你了解哪些优化器，实际项目中怎么选择"
5. "[你方向的专题问题：如'请介绍一下推荐系统的召回-排序架构' 或 '请讲解一下目标检测的主要方法']"

格式要求：
- 先说结论（BLUF：Bottom Line Up Front）
- 再解释原因/机制
- 最后说适用场景或局限
- 控制在 1.5 分钟内
```

把这 5 个答案保存到你的"面试回答库"文件。

---

## 🚀 完整版任务（45 分钟）

### 步骤 1：整理 10 个核心面试题（20 分钟）

除了上面的 5 个，再补充 5 个方向专题题：

```
请帮我整理 [你的方向] 方向，机器学习工程师面试中最高频的 5 道题的答案模板：
每个答案：
- 关键词（记忆锚点）
- 1-2 分钟口述版本
- 追问题（面试官可能会追问什么）
```

### 步骤 2：练习"STAR 法则"（15 分钟）

> STAR = Situation（背景）+ Task（任务）+ Action（行动）+ Result（结果）

准备 1 个"项目经验"回答（即使没有完整项目，用你的复现练习也行）：

```
帮我用 STAR 法则整理这段经历：
我在这 3 周里复现了 [某个模块]，遇到了 [某个问题]，解决方式是 [xxx]，结果 [xxx]。
请帮我把这段话整理成 2 分钟的面试回答。
```

### 步骤 3：建立面试回答库（10 分钟）

创建一个新文件，把今天所有答案整理进去，按以下结构：

```markdown
# 我的面试回答库

## 通用基础题
- Transformer 工作原理：[你的答案]
- 过拟合处理方法：[你的答案]
- ...

## 方向专题题
- [方向] 题 1：[你的答案]
- ...

## 项目经历
- 项目/复现经历：[STAR 版本]
```

## 🤖 今日 AI 提示词

### 提示词 1：答案优化
```
这是我对 [问题] 的回答：
[你的答案]
请帮我优化：
1. 更清晰的结构（先结论后解释）
2. 更简洁（去掉啰嗦的部分）
3. 增加一个具体例子使答案更有说服力
```

### 提示词 2：追问准备
```
如果面试官问了这道题：[问题]
我回答了：[你的答案]
请预测 3 个最可能的追问，并给我每个追问的答案要点。
```

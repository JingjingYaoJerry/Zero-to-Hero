## 🚀 最终模拟面试（45 分钟）

### 规则
- **完全不看笔记**
- 用真实面试的节奏和方式
- 完成后做诚实的自我评估

### 第一轮：45 分钟完整面试

```
请扮演一位资深机器学习团队的技术面试官，对我进行一次完整技术面试。
面试时长：45 分钟（按正常面试节奏）

面试大纲：
- 开场（5 分钟）：请你自我介绍，重点说说你最近学过的技术方向
- 基础原理（15 分钟）：3-4 道基础技术题
- 方向专题（10 分钟）：2 道深度方向题
- 工程实践（10 分钟）：1-2 道工程/系统题
- 开放问题（5 分钟）：你有什么想问我的？

请模拟真实面试节奏，不要一次出所有题，而是一问一答地进行。
等我完整回答每道题后，继续下一题（暂时不给反馈，面试结束后集中反馈）。

开始面试。
```

### 第二轮：面试反馈（15 分钟）

完成面试后：

```
面试结束。
请给我全面的面试反馈：
1. 整体评分（1-10）
2. 每道题的得分和点评
3. 最突出的 3 个优点
4. 最需要改进的 3 个方面
5. 如果你是面试官，你会 pass 还是 fail，理由是什么
6. 如果我明天要真实面试，今晚最应该复习什么
```

### 步骤 3：理解核心概念（8 分钟）

**反向传播的 3 步：**
```
1. 前向传播：输入 → 逐层计算 → 输出预测值
2. 计算损失：预测值 vs 真实值 → loss
3. 反向传播：loss → 逐层计算梯度（用链式法则）→ 更新参数
```

**链式法则（直觉）：**
```
如果 y = f(g(x))
那么 dy/dx = dy/dg * dg/dx

在神经网络里：
loss = L(out(hidden(input)))
∂L/∂w = ∂L/∂out * ∂out/∂hidden * ∂hidden/∂w
```

**梯度消失的原因：**
- Sigmoid 函数的导数最大只有 0.25
- 多层相乘后：0.25 × 0.25 × ... → 接近 0
- 解决方法：ReLU（导数为 1 或 0）、残差连接、LayerNorm

**梯度爆炸的原因：**
- 权重较大时，反向传播中梯度会越乘越大
- 解决方法：梯度裁剪（gradient clipping）

## 🆘 卡住了怎么办

**"链式法则看不懂"**  
→ 忘掉数学，记住这个比喻：链式法则就是"连锁反应"——A 影响 B，B 影响 C，那么 A 怎么影响 C = A 影响 B 的程度 × B 影响 C 的程度

**"梯度消失的原因不清楚"**  
→ 只记住：Sigmoid 的导数最大只有 0.25，多层相乘后接近 0；ReLU 的导数是 1 或 0，不会消失

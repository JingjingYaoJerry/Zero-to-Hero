### 步骤 2：精读关键部分（10 分钟）

你不需要读整篇论文，重点读/理解：

1. **Adam 的更新公式**（就 4 行）：
   ```
   m_t = β₁ * m_{t-1} + (1 - β₁) * g_t        # 一阶动量
   v_t = β₂ * v_{t-1} + (1 - β₂) * g_t²        # 二阶动量
   m̂_t = m_t / (1 - β₁ᵗ)                       # 偏差修正
   v̂_t = v_t / (1 - β₂ᵗ)                       # 偏差修正
   θ_t = θ_{t-1} - α * m̂_t / (√v̂_t + ε)       # 参数更新
   ```
2. 理解为什么 **偏差修正（bias correction）** 是必要的（初始时 m 和 v 都偏向 0）
3. 记住默认超参数：`β₁=0.9, β₂=0.999, ε=1e-8, lr=0.001`

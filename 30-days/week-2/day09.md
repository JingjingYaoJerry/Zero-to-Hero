### 步骤 3：理解核心概念（8 分钟）

**退化问题（Degradation Problem）：**
- 理论上：更深的网络表达能力更强
- 实践中：超过一定深度后，训练误差反而上升
- 原因：不是过拟合，是优化困难（梯度消失）

**残差连接的解法：**
```
普通层：学习 H(x)（直接映射）
残差层：学习 F(x) = H(x) - x（残差/增量）
        输出：F(x) + x = H(x)
```

**为什么更容易学习：**
- 最坏情况：F(x) 学成 0，输出就是 x（恒等映射）
- 梯度路径：残差支路 + identity 支路，梯度至少有一条路能传回去

**Bottleneck 结构（ResNet-50/101/152）：**
```
1×1 conv（降维）→ 3×3 conv（提取特征）→ 1×1 conv（升维）
```

## 🆘 卡住了怎么办

**"退化问题搞不清楚"**  
→ 记住：退化 ≠ 过拟合。退化是训练误差也上升，说明模型没有充分被优化

**"残差连接直觉不清楚"**  
→ 记住：残差连接等于在告诉网络"如果你不知道要学什么，就学'什么都不做'（F(x)=0）"

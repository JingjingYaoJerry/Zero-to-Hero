# 第 21 天：第三周复盘——你的方向积累了多少？

> 💡 **今天只需要 20 分钟就能完成最小版本**

---

## 📋 今日概览

第三周你进入了方向专题，学了 BERT、GPT，以及你选择方向的 2-3 篇论文。  
今天的问题：**你能把一个方向的演进逻辑说清楚吗？**

---

## ⏱️ 最小启动版本（20 分钟）

**做一件事：用 AI 做 15 分钟方向专题模拟面试**

```
我正在准备 [NLP / CV / 推荐 / 传统ML] 方向的机器学习工程师面试。
请扮演面试官，针对这个方向出 5 道面试题，从简单到难。
每出 1 题等我回答，给我评分（1-5）并指出遗漏点，再出下一题。
```

完成 5 道题就算完成今天。

---

## 🚀 完整版复盘（45 分钟）

### 步骤 1：方向演进梳理（15 分钟）

用 AI 帮你整理你的方向内部的演进：

```
请帮我梳理 [你的方向] 最重要的 5 个里程碑论文/方法，
按时间顺序，说明每个解决了上一个什么问题。
这将成为我面试时"谈谈这个领域的发展"的答案框架。
```

把结果保存到笔记里，这是你面试时最有价值的内容之一。

## 🤖 今日 AI 提示词

### 提示词 1（方向演进）
```
[方向] 方向的演进：从 2015 年到现在，最重要的 5 个发展节点是什么？
每个节点：发表时间、代表论文/方法、解决了什么问题、为什么重要
格式化成我可以背诵的答题框架。
```

### 提示词 2（综合连接）
```
帮我把这 3 周学到的内容，整理成一个连贯的技术故事：
从基础训练技巧（Adam、Dropout、BN）
→ 基础模型结构（ResNet、Transformer）
→ 预训练方法（BERT、GPT）
→ 我的方向专题

重点说明：每个发展解决了什么问题，引入了什么新问题
```

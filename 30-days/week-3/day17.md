## 🔤 方向 A：NLP / 大模型

### 今日论文：LoRA

**论文：** *LoRA: Low-Rank Adaptation of Large Language Models*（Hu et al., 2022）

**最小版本提示词（10 分钟）：**
```
请讲解 LoRA（Low-Rank Adaptation）：
1. LoRA 解决了什么问题（大模型微调的挑战）
2. 低秩分解的思想是什么
3. LoRA 如何在不改变原始模型参数的情况下微调
4. r 参数（rank）的含义和选择
5. LoRA 和全量微调的对比（参数量、效果、速度）
6. 面试 1 分钟回答
```

**核心要点：**
- 大模型有数十亿参数，全量微调需要大量显存
- LoRA 思想：原始权重矩阵不动，在旁边加两个小矩阵 A 和 B
- 增量 = A × B（低秩分解），参数量极少
- 训练时只训练 A 和 B，推理时合并到原权重里

## 👁️ 方向 B：计算机视觉

### 今日论文：Vision Transformer (ViT)

**论文：** *An Image is Worth 16x16 Words*（Dosovitskiy et al., 2021）

**最小版本提示词（10 分钟）：**
```
请讲解 Vision Transformer（ViT）：
1. ViT 如何把图像变成序列（patch 化的思路）
2. ViT 和 CNN 的根本区别（inductive bias）
3. 为什么 ViT 在大数据集上比 CNN 好
4. ViT 的局限性（小数据集效果差）
5. 面试 1 分钟回答
```

**核心要点：**
- 把图像切成 16×16 的小块（patch），每个 patch 变成一个 token
- 直接用 Transformer 处理这些 token 序列
- CNN 有局部归纳偏置（局部特征），ViT 没有（需要更多数据学习）
- 大数据集上 ViT 超越 CNN；小数据集上 CNN 更好

## 📊 方向 C：推荐 / 广告

### 今日论文：Wide & Deep

**论文：** *Wide & Deep Learning for Recommender Systems*（Cheng et al., 2016）

**最小版本提示词（10 分钟）：**
```
请讲解 Wide & Deep：
1. 推荐系统中"记忆"和"泛化"的矛盾
2. Wide 部分（线性模型）学什么
3. Deep 部分（神经网络）学什么
4. 为什么联合训练比分开训练好
5. 面试 1 分钟回答
```

**核心要点：**
- Wide：广义线性模型，记忆特征共现（如"用户买过 X 还买了 Y"）
- Deep：深度神经网络，学习特征泛化（理解新组合）
- 联合训练：同时优化两部分，端到端

# 📋 每日学习日志模板

> 使用方法：每天学习后（或者学习时），填写这个日志。  
> 简短即可，5 分钟就能填完。长期坚持比写得详细更重要。

---

## 格式

```markdown
## [日期] Day [X] 学习日志

**今天学了：** [论文名/概念]
**实际学习时长：** [xx 分钟]
**完成了哪些步骤：** [最小版本 / 完整版 / 可选加餐]

**今天最大的收获（1-2 句）：**

**今天最不确定的地方（1 句）：**

**明天复习提醒：** [需要复习今天哪个知识点]

**今天的状态：** 🟢 状态好 / 🟡 普通 / 🔴 拖延了
```

2. **记录格式**：错误内容 → 为什么错 → 正确理解
3. **复习频率**：每周看一遍所有条目，重点复习 ❌ 标的

## 我的错题

### [日期] 错题：示例 — BN 和 LN 搞混了

**错误内容：** 我以为 BatchNorm 和 LayerNorm 的区别只是计算维度不同  
**正确理解：** BN 在 batch 维度归一化（依赖 batch size），适合 CNN；LN 在每个样本的特征维度归一化（独立于 batch），适合 Transformer/RNN/小 batch 场景  
**为什么会出错：** 只记住了"归一化"，没记住"在哪个维度上"  
**记忆方法：** BN = "batch"的 Norm，需要一批数据一起算；LN = "layer"的 Norm，一个样本自己算  
**状态：** ⚠️ 部分掌握

## 常见概念混淆对

> 经常一起搞混的概念，集中在这里

| 概念 A | 概念 B | 关键区别 |
|-------|-------|---------|
| BatchNorm | LayerNorm | BN 在 batch 维度，LN 在特征维度 |
| Precision | Recall | Precision = 预测正的有多少真的正，Recall = 真正的有多少被预测到 |
| Overfitting | Underfitting | 过拟合 = 训练好测试差，欠拟合 = 训练测试都差 |
| BERT | GPT | BERT = Encoder 双向，GPT = Decoder 单向 |
| Dropout 训练 | Dropout 推理 | 训练时随机关掉，推理时全开但乘以 (1-p) |
| 梯度消失 | 梯度爆炸 | 消失 = 梯度越乘越小，爆炸 = 越乘越大 |
| SVM 硬间隔 | SVM 软间隔 | 硬 = 不允许误分类，软 = 允许一些误分类（C 参数控制）|
| Skip-gram | CBOW | Skip-gram = 中心词预测上下文，CBOW = 上下文预测中心词 |
| Self-Attention | Cross-Attention | Self = 序列和自己 attention，Cross = 序列和另一个序列 attention |
| 方差 Variance | 偏差 Bias | 方差 = 模型对不同训练集的敏感程度，偏差 = 模型的系统性错误 |

# 🤖 AI 提示词大全

> 所有提示词都可以直接复制使用。  
> 适用于：ChatGPT、Claude、Gemini、文心一言、通义千问等。

---

## 一、论文速读类

### 1.1 通用论文速读提示词

```
请用机器学习工程师能理解的方式，概括这篇论文：
1. 解决了什么问题（之前的方法有什么不足）
2. 核心方法是什么（最关键的创新点）
3. 关键公式/结构的含义（直觉解释，不要只写符号）
4. 和之前方法相比，优势在哪里
5. 主要局限性是什么
6. 如果要复现，最容易出错的地方是什么
7. 面试时用 1 分钟讲清楚这篇论文，答案是什么

论文：[在这里粘贴论文标题或摘要]
```

### 1.2 逐段解释提示词

```
请逐段解释这篇论文的方法部分：
- 重点解释每个公式的含义和来源
- 每个模块的作用，以及为什么这样设计
- 如果某些推导可以跳过，请明确指出哪些是必须理解的
- 以机器学习工程师的视角，而不是数学家的视角来解释

论文方法部分：[粘贴论文 Method 部分]
```

### 1.3 直觉优先解释

```
请用直觉而不是数学公式，解释这个概念：[概念名]
要求：
- 用 1 个类比或比喻
- 用 3 句话说明为什么它有效
- 说明什么时候应该用它，什么时候不应该用
- 最后给一句话总结
```

## 二、主动回忆/自测类

### 2.1 自测题生成

```
请根据这篇论文，出 10 道从易到难的自测题：
- 2 道：核心概念（能不能用自己的话解释）
- 2 道：公式/结构理解（为什么这样设计）
- 2 道：和其他方法对比（优缺点）
- 2 道：工程应用（实现/调参/debug）
- 2 道：局限性和改进方向

等我逐题回答后，给我打分（1-5）和纠错。

论文：[论文名]
```

### 2.2 间隔复习自测

```
我上周学过以下内容：[列出论文/概念]
请为每个概念出 1 道简短的自测题，等我回答后指出我遗漏的关键点。
从最基础的开始，到最复杂的结束。
```

### 2.3 对比自测

```
请出 5 道对比题，考察我对以下概念对的区别：
- [概念 A] vs [概念 B]

每道题：先我回答，然后你指出对的部分和遗漏的部分。
```

## 三、深度理解类

### 3.1 工程角度深化

```
请把这篇论文转成工程视角：
1. 输入输出格式（数据长什么样）
2. 模型结构如何实现（关键代码思路）
3. 训练时最容易出错的 3 个地方
4. 推理时的性能瓶颈
5. 如何做 ablation（消融实验）验证哪个组件最重要
6. 上生产环境需要注意什么
7. 如何 debug 训练不收敛

论文：[论文名]
```

### 3.2 概念连接分析

```
请帮我把这 3 个概念连接起来，解释它们在训练神经网络中各自的作用和相互关系：
[概念 1]、[概念 2]、[概念 3]

重点说明：
- 它们各解决什么问题
- 它们之间有没有冲突或互相影响
- 在同一个模型里，它们的位置和执行顺序
```

### 3.3 为什么这样设计

```
针对这篇论文，请深入解释"为什么这样设计"：
论文：[论文名]
我想理解的设计选择：[具体设计，如"为什么用 softmax 而不是 sigmoid"]

请从以下角度解释：
1. 这个设计解决了什么具体问题
2. 有没有其他备选方案，为什么没选那些
3. 这个设计有什么数学上的合理性（直觉即可）
4. 实验上如何验证这个设计是最好的
```

## 四、面试准备类

### 4.1 面试回答模板生成

```
请把这篇论文整理成面试回答模板：
论文：[论文名]

格式要求：
- 开场（1 句话：这篇论文解决了什么问题）
- 核心方法（2-3 句话：怎么解���的）
- 为什么有效（1-2 句话：直觉解释）
- 局限性（1 句话）
- 我的理解/复现（可选：如果你有的话）

总时间：1.5 分钟口述版
```

### 4.2 AI 模拟面试

```
请扮演一位资深机器学习工程师面试官，对我进行技术面试。
面试主题：[你指定的主题，如 "Transformer 架构" 或 "推荐系统设计"]

规则：
- 每次出 1 道题
- 等我完整回答后，给我评分（1-5）
- 指出我遗漏的关键点
- 然后出下一题
- 5 题后给我综合反馈

从最基础的题目开始。
```

### 4.3 面试追问预演

```
我刚才回答了这道面试题：[问题]
我的回答是：[你的回答]

请：
1. 预测面试官最可能追问的 3 个问题
2. 为每个追问给我答题要点
3. 告诉我我的回答有哪些地方可以更强
```

### 4.4 综合答题框架

```
面试题：[题目]
请给我这道题的满分答题框架：
1. 答题结构（先说什么后说什么）
2. 不能遗漏的关键词
3. 加分的深度点（让答案有层次感）
4. 常见错误（很多人会答错什么）
5. 1.5 分钟口述示范
```

## 五、对比分析类

### 5.1 生成对比表

```
请帮我做一张 [概念 A] vs [概念 B] 的对比表：

对比维度：
- 核心思想
- 结构/机制
- 训练方式
- 优点
- 缺点
- 适合场景
- 代表应用

最后加一句"面试一句话总结"。
```

### 5.2 演进路径梳理

```
请帮我梳理 [某个领域] 从 [起点方法] 到 [终点方法] 的演进路径：

格式：
1. 每个阶段的代表方法（按时间）
2. 每个方法解决了前一个方法的什么问题
3. 每个方法引入了什么新问题
4. 面试时讲这个演进的 3 分钟版本框架
```

## 六、工程实践类

### 6.1 代码实现辅助

```
我想实现 [论文名] 的核心模块：[模块名]
请给我：
1. 最小实现的伪代码（10-20 行）
2. PyTorch 实现（如果适用）
3. 最容易出错的 3 个地方
4. 如何验证实现是否正确（输入/输出检查）
5. 和官方实现相比，我的简化版缺少了什么
```

### 6.2 Debug 辅助

```
我在实现/使用 [模型/方法] 时遇到了以下问题：
[错误信息或现象]

代码如下：
[代码]

请帮我：
1. 指出最可能的原因
2. 给我 debug 步骤
3. 如何避免这类问题
```

### 6.3 调参建议

```
我在训练 [模型] 时，遇到以下情况：
[描述：如 loss 不下降、过拟合、训练不稳定等]

请给我：
1. 最可能的原因（按优先级排列）
2. 每个原因对应的解决方法
3. 如何系统性地排查（不要乱猜，要有序）
```

## 七、记忆巩固类

### 7.1 间隔复习题

```
我在 [X] 天前学了 [论文/概念]。
请出 5 道复习题帮我检验记忆：
- 重点考察我之前容易出错的地方
- 从最基础的开始
- 每题等我回答后反馈，再出下一题
```

### 7.2 遗忘检测

```
请用 5 道问题，检测我对 [概念] 的理解深度：
- 如果我能回答前 2 题，说明基础没忘
- 如果能回答前 4 题，说明理解不错
- 如果 5 题全对，说明掌握扎实

等我逐题回答。
```

### 7.3 最小记忆锚点

```
针对 [论文/概念]，帮我找到最小记忆锚点：
- 即使忘了所有细节，只要记住这 3 件事，我就能在面试中撑起基本答案
- 每个锚点用 1 句话表达
- 给我一个帮助记住这 3 个锚点的记忆法（如首字母缩写、故事）
```

## 八、快速使用指南

| 场景 | 使用哪个提示词 |
|-----|--------------|
| 读新论文前不知道从哪开始 | 1.1 通用论文速读 |
| 论文看了看不懂 | 1.3 直觉优先解释 |
| 想检验自己学会了没有 | 2.1 自测题生成 |
| 隔了几天想复习 | 2.2 间隔复习自测 |
| 老是搞混两个概念 | 2.3 对比自测 / 5.1 生成对比表 |
| 想搞清楚工程实现 | 3.1 工程角度深化 |
| 面试前 1 天准备 | 4.1 面试回答模板 + 4.2 模拟面试 |
| 被问到没准备过的题 | 4.4 综合答题框架 |
| 代码跑不起来 | 6.2 Debug 辅助 |
| 模型训练有问题 | 6.3 调参建议 |
